## VIS 逐项判断

### VIS-01 — 回放时间、播放/暂停、拖动

**Pass。**

- `web/robot_renderer/src/physical.ts:22-25` 提供播放、回到起点、倍速、时间轴、事件定位和“回放不影响后台执行”的明确 UI。
- `web/robot_renderer/src/physical.ts:34-34,68-84` 使用独立 `cursor` 与 `requestAnimationFrame` 驱动回放；暂停后不会被页面轮询重置。
- `web/robot_renderer/src/physical-frame.ts:4-19` 对相邻真实帧做位置线性插值，离散阶段/布尔状态从左帧保持到下一采样点。
- 独立浏览器结果 `baseline_play_pause_seek_switch=pass`：播放跨过 1 秒刷新窗口后时间继续推进；暂停等待后时间保持；继续后再次推进；拖动到 4000ms 后切换 SVG 保持相同时间和物体坐标；最终帧与同一 artifact 的 `trajectory.jsonl` 一致。

### VIS-02 — 终态按钮恢复、连续启动

**Pass。**

- `app.py:1814-1829` 的轮询 fragment 在终态执行一次页面级 rerun；`app.py:1842-1859` 仅在 queued/running 时禁用启动，终态显示结果与回放。
- 独立浏览器结果 `offset_failure_event_and_restart=pass`：不刷新页面切换到 `offset-grasp` 后可再次启动；失败终态启动按钮仍可用；清除当前运行引用后启动按钮可用。
- 未观察到此前“worker 已终态但按钮仍禁用”的缺陷。

### VIS-03 — SVG 呈现、米制坐标、同一时刻

**Pass（本轮约定的工具/物体/目标示意范围）。**

- `robot_mvp/v2_view.py:12-32` 从 `artifact_to_renderer_payload` 读取运行产物并挂载 V2 renderer；`robot_mvp/v2_view.py:35-50` 保留结果与原始环境可复查入口。
- `web/robot_renderer/src/physical-frame.ts:22-24` 明确 MuJoCo Z-up 到 Three.js Y-up 的坐标转换和米制 SVG 投影。
- `web/robot_renderer/src/physical.ts:19-25,63-76` 明确标注“非真实机器人几何重建”、坐标单位 m，并让 SVG/3D 共用 `samplePhysicalFrame` 的同一帧。
- 独立截图显示 SVG 是实际图形，不是 HTML/SVG 源码块；浏览器断言 `pre code` 数量为 0、SVG 与物体节点可见、切换前后 `data-object-position` 和 `data-time-ms` 一致。
- 强制 `HTMLCanvasElement.getContext('webgl')` 返回空值时，独立结果 `webgl_unavailable_svg_playback=pass`，页面显示“已回退 SVG”，仍可播放。

### VIS-04 — 深色主题可读性与结构化报告

## 影响与剩余范围

本轮修复已经闭合了原缺陷核验中最直接的五类浏览器问题：回放不再静态、终态可再次启动、SVG 不再展示源码、物理视图明确使用米制示意且两渲染器同步、页面报告能回指运行结果。独立证据支持这一结论，但范围只到当前本地服务、当前 Chromium、当前 baseline/offset 两条运行链路和已列出的 V2 回放控件。

门禁状态不是 `Changes required`；也不是无条件 `Passed`。若下一轮要扩大为完整 V2 放行，最有价值的补验是异常/损坏 artifact、worker crash/timeout、窄屏/辅助技术可读性，以及与 PRD/接口契约的完整字段级报告审计。
