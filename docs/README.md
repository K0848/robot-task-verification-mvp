## 当前基线

项目是一个本地单机 MVP。`app.py` 负责 Streamlit 页面编排，`robot_mvp/` 负责领域模型、模拟运行、状态投影和 JSON 存储，`web/robot_renderer/` 负责 Three.js 动作渲染。真实机器人、ROS、线上数据库、多用户和权限系统不在当前产品边界内。

当前核心闭环是：

```text
选择策略和场景 → 启动运行 → 实时投影 → 生成结论 → 回放/对比 → 批量评测
```

## 迭代入口

每次迭代先回答三件事：

1. 用户得到的结果或行为是否发生变化；
2. 哪个数据对象或协议成为事实来源；
3. 哪些状态、异常、降级和验收规则需要同步更新。

如果只是视觉调整，检查架构文档中的渲染边界；如果涉及字段、状态或跨模块调用，必须更新接口契约并补充相应测试。
