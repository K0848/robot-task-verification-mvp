# 中间物理测试证据的资源口径

本目录是 2026-09-22 的中间验证：同一个作者测试进程直接调用 `run_panda`，并在两次策略首轮后创建原生 Renderer 生成截图。这里的 `peak_working_set_bytes` 是该测试进程自启动以来的峰值，包含截图渲染器，**不是独立 worker 峰值**。运行成功/失败与原生关键帧仍是有效的固定条件证据，但不作为最终 worker 内存基线。

之后执行器已改为每轮通过 `V2JobManager` 启动独立 worker，原生截图只在父进程生成。最终资源入口为 [带进程ID核对的独立worker结果](../panda-workers-audited-20260922/results.json)，并断言性能记录PID等于实际子进程PID且不同于截图父进程。早期数据保留用于追溯，不合并两种统计口径，也不改写原始测量值。
